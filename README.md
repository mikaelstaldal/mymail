# MyMail

A self-hosted, single-user email client with folders, rich-text composition, threading, search, scheduled sends, and snooze. Runs alongside a local mail server such as Postfix.

Go backend, SQLite storage, a REST API, and an embedded web interface, shipped as a single binary.

[Live demo](https://mikaelstaldal.github.io/mymail/) · [Android app](https://github.com/mikaelstaldal/mymail-android)
