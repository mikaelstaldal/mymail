Spam Filter
Configure automatic spam detection based on headers added by your mail server (e.g. SpamAssassin). Messages classified as spam are routed to the Junk folder.
Enable spam filtering
Messages flagged as spam by your MTA will be delivered to Junk instead of Inbox
Score-based detection
Header added by SpamAssassin (default: X-Spam-Score)
Route to Junk if score ≥ this value
Threshold 5.0:  
  scores ≥ 5.0 → Junk
Header flag detection (always active when spam filter is enabled)
X-Spam-Flag: YES  → Junk
X-Spam-Status: Yes, …  → Junk
These headers are checked in addition to the score threshold. Either a flag match or a score breach triggers spam routing.
