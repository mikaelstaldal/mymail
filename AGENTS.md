# mymail

A self-hosted personal (single-user) email client with backend storage, REST API, and embedded web UI.

## Specification

This project is currently in specification phase, there is no implementation yet. Do not actually implement anything 
yet, only work on the specification in SPEC.md, REST API specification in docs/openapi.yaml and web UI mockups in 
mockups/

ISSUES.md contains any currently open issues with the specification.
