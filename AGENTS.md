# mymail

A self-hosted personal (single-user) email client with backend storage, REST API, and embedded web UI.

## Specification

This project is currently in specification phase, there is no implementation yet. Do not actually implement anything 
yet, only work on the specification documents in spec/, REST API specification in openapi.yaml and web UI mockups in 
mockups/

- REQUIREMENTS.md — high-level functional requirements (what the system does)
- IMPLEMENTATION.md — implementation plan with technical details (how to build it)

ISSUES.md contains any currently open issues with the specification.
